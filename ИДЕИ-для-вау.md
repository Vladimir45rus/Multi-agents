# Что сделает приложение «божественным»

Дата: 17.11.2026. Основано на текущем состоянии кода (v1.6.0): роли, оркестратор с проверками, Team mode, Фома-скептик и голосование, визуальный конструктор превью, SSE-стриминг, локальная БД, Electron.

Ниже — не «список фич», а то, что **меняет первое впечатление и доверие**. Отсортировано по силе эффекта на пользователя.

---

## P0. То, без чего «вау» не случится

### 1. Первый запуск: из идеи в работающее приложение за 90 секунд

**Сейчас:** открывается пустое дерево, нужно вставить ключ, придумать папку, нажать «пресет». Человек не понимает, что делать, и закрывает.

**Нужно:** экран-онбординг на весь экран:

```
Что строим?
[ описание в свободной форме ]            [🎙 голосом]

Шаблоны-подсказки: дневник калорий · трекер привычек · лендинг · CRM

кнопка: [Создать и запустить]
```

Дальше автоматически: папка → шаблон → агенты обсуждают (видно) → патч → проверки → **превью открывается само**. Человек ничего не настраивал, а через полторы минуты у него работает приложение.

**Почему гениально:** это единственный момент, когда продукт можно «почувствовать» без объяснений. Сейчас его нет.

**Что уже есть:** `/api/templates`, создание папки, оркестратор, превью. Нужен один экран и цепочка вызовов. **2–3 дня.**

---

### 2. Командная палитра (Ctrl+K)

**Сейчас:** 20+ действий разбросаны по кнопкам, часть — только в настройках.

**Нужно:** одна палитра: «открыть папку», «новый проект», «запустить превью», «остановить оркестратор», «переключить модель Главного», «показать логи», «откатить файл», «отправить ТЗ агенту X». Поиск по подписи + горячие клавиши.

**Почему гениально:** дешёвый признак «взрослого» инструмента. Люди судят по Ctrl+K.

**Что уже есть:** все действия — это существующие функции. **1 день.**

---

### 3. Живой дифф и машина времени

**Сейчас:** агент пишет файлы, есть история и откат по файлу, но пользователь не видит **что именно изменилось** и не может отмотать задачу целиком.

**Нужно:**

- панель «Изменения»: список файлов задачи, дифф в стиле GitHub, кнопки «Принять / Отклонить»;
- таймлайн задачи: каждый шаг (план, совет, патч, проверка, фикс) — точка, по клику дифф;
- «Откатить всю задачу» одной кнопкой (у нас есть `workspace_file_history` — данные уже пишутся).

**Почему гениально:** это то, что отличает «ИИ что-то сделал» от «ИИ работает под моим контролем». Доверие = возможность отменить.

**Что уже есть:** история патчей с бэкапами, события оркестратора, откат файла. **3–4 дня.**

---

### 4. «Почему так?» — клик по элементу → код, который его рисует

**Сейчас:** конструктор умеет выбирать элемент, двигать и стилизовать, но не показывает, **где это в коде**.

**Нужно:** в конструкторе кнопка «Показать код» → открывается файл и строка, где отрендерен этот элемент (по классу/тексту/структуре), с подсветкой.

**Почему гениально:** это мост между «я вижу» и «я правлю». Ни у кого в вебе это не сделано так прямо.

**Что уже есть:** селектор и DOM-путь в инспекторе, поиск по проекту, редактор с переходом на строку. **2 дня.**

## P1. То, что делает продукт «своим»

### 5. Заседание команды как экран

Агенты уже дают вердикты `approve/change/blocker`, Фома блокирует, Главный отвечает. Но это видно только в логах.

**Нужно:** экран «Совещание»: карточки агентов (роль, вердикт, цитата), конфликты подсвечены, блокеры Фомы — красным, внизу — решение Главного и его ответы на блокеры. Кнопка «Пересмотреть».

**Почему:** это ваша уникальная фича — «команда», а не «один агент». Её надо **показывать**, а не хранить в событиях. **2 дня.**

### 6. Панель стоимости и лимитов

Токены и деньги по задаче, агенту, модели; бюджет на день; предупреждение при превышении; «дешёвая модель на ревью, дорогая на Главного» — как рекомендация.

**Почему:** без этого люди боятся включать автономный режим. **2 дня.**

### 7. Локальные модели в один клик

Кнопка «Локально (Ollama)»: автопоиск `localhost:11434`, список моделей, проверка. Для части аудитории «работает без интернета и без оплаты» — это и есть «гениально».

**Что уже есть:** кастомные провайдеры, `baseUrl`, локальный HTTP разрешён. Нужен пресет и автодетект. **1–2 дня.**

### 8. Скриншот → правка

Вставить скриншот бага или макета в чат: «сделай как здесь». Мультимодальные модели уже поддерживаются провайдерами.

**Почему:** дизайнеры и заказчики мыслят картинками. **2–3 дня** (нужна передача изображений в запрос).

## P2. Полировка до «идеально»

9. **Голосовые команды** — «сделай кнопку красной», «запусти проверки». Микрофон уже есть, нужен разбор в действие.
10. **Git-режим**: ветка на задачу, коммит с осмысленным сообщением, PR-описание из отчёта.
11. **Библиотека ролей**: наборы агентов под стек (React, Flutter, бэкенд) — импорт одним кликом.
12. **Отчёт как артефакт**: markdown + скриншот превью + список изменений, кнопка «Скопировать в PR».
13. **Демо-режим**: «Покажи, что умеешь» — прогон на встроенном примере за 2 минуты (для видео и первых впечатлений).
14. **Тёмная/светлая тема до конца**: сейчас тема есть, но часть панелей игнорирует её.
15. **Экспорт проекта в ZIP/установщик** прямо из IDE.

## Что бы я сделал первым (порядок на неделю)

| День | Задача | Результат |
|---|---|---|
| 1 | Онбординг «идея → запуск» | первый запуск перестаёт быть пустым |
| 2 | Командная палитра Ctrl+K | ощущение взрослого инструмента |
| 3–4 | Панель изменений + откат задачи | доверие к агентам |
| 5 | «Почему так?» в конструкторе | связка «превью ↔ код» |
| 6 | Экран «Совещание» | уникальность видна глазами |
| 7 | Панель стоимости | снимает страх автономности |

После этого у продукта есть **история на 60 секунд** для видео: идея → команда спорит → Фома блокирует → Главный отвечает → патч → проверки → превью → откат одной кнопкой.

## Чего не хватает не в функциях, а в подаче

- **Один сценарий в README и на первом экране**, а не список возможностей.
- **Демо-гифка 40 секунд** — без неё проект не пересылают.
- **Английский первым** — русский вторым.
- **Понятная ошибка вместо «failed»**: если нет ключа — «вставьте ключ OpenRouter, это 30 секунд» с кнопкой.

---

## Итог

Сейчас приложение умеет **больше**, чем показывает. Гениальность тут не в новых агентах, а в трёх вещах:

1. **первый запуск без пустоты**,
2. **видимый контроль** (диффы, таймлайн, откат),
3. **связка «увидел → понял, где код → поправил»**.

Всё остальное — усиление.
