# Политика конфиденциальности Программы «Multi-Agent Code Studio»

### 1. Отсутствие сбора персональных данных Разработчиком
1.1. Программа «Multi-Agent Code Studio» не осуществляет сбор, передачу, хранение или обработку персональных данных Пользователя на серверах Разработчика.
1.2. В Программе отсутствует телеметрия, трекинг действий, сбор логов ошибок или аналитика использования.

### 2. Локальное хранение данных
2.1. Все данные (история чатов, структуры проектов, настройки, шифрованные API-ключи и токены) хранятся исключительно на локальном диске Пользователя в базе данных SQLite (`dev.db`).
2.2. Удаление Программы или пользовательской директории приводит к полному уничтожению всех сохраненных данных.

### 3. Передача данных сторонним сервисам
Передача данных во внешнюю сеть осуществляется исключительно по инициативе Пользователя и только в следующие точки назначения:

* **AI-провайдеры (OpenAI, Anthropic, OpenRouter и др.):** отправляются промпты и фрагменты кода проекта для работы агентов.
* **GitHub API:** отправляется код проекта и токен при выполнении операции `push`.
* **Telegram API:** отправляются уведомления, если Пользователем настроен Telegram-бот.
* **Сервис туннелирования (localtunnel):** используется для транзита трафика при явном включении функции мобильного удаленного доступа.
* **GitHub Releases:** используется модулем `electron-updater` исключительно для проверки наличия новых версий приложения.

### 4. Контакты
По всем вопросам работы Программы или условий использования вы можете связаться с Разработчиком через репозиторий проекта на GitHub.
